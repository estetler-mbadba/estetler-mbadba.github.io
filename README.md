# College data projects

The home page for three analyses of college data, each built from public federal records with SQL and an AI coding agent.

**Live page:** https://estetler-mbadba.github.io/

| Project | Live | Code |
|---|---|---|
| Enrollment in public data: Kenyon College | https://estetler-mbadba.github.io/kenyon-enrollment-insights/ | [kenyon-enrollment-insights](https://github.com/estetler-mbadba/kenyon-enrollment-insights) |
| Five Colleges of Ohio enrollment atlas | https://estetler-mbadba.github.io/ohio-five-enrollment-atlas/ | [ohio-five-enrollment-atlas](https://github.com/estetler-mbadba/ohio-five-enrollment-atlas) |
| Athletics Benchmarking Explorer | https://estetler-mbadba.github.io/athletics-benchmarking-explorer/ | [athletics-benchmarking-explorer](https://github.com/estetler-mbadba/athletics-benchmarking-explorer) |

This page is static HTML and CSS with no build step. The projects are independent analyses of public records and are not affiliated with or endorsed by any college, consortium, conference, or athletic association named in them.
