# College data projects

The home page for four college data projects built with an AI coding agent and checked: a weekly admissions pacing report on synthetic records, two analyses of public federal records, and a program-to-career explorer.

**Live page:** https://estetler-mbadba.github.io/

|---|---|---|

| Five Colleges of Ohio enrollment atlas | https://estetler-mbadba.github.io/ohio-five-enrollment-atlas/ | [ohio-five-enrollment-atlas](https://github.com/estetler-mbadba/ohio-five-enrollment-atlas) |
| Athletics Benchmarking Explorer | https://estetler-mbadba.github.io/athletics-benchmarking-explorer/ | [athletics-benchmarking-explorer](https://github.com/estetler-mbadba/athletics-benchmarking-explorer) |
| Program-to-Career Explorer | https://estetler-mbadba.github.io/program-career-explorer/ | [program-career-explorer](https://github.com/estetler-mbadba/program-career-explorer) |

This page is static HTML and CSS with no build step. The projects are independent work. Those built on public records are not affiliated with or endorsed by any college, consortium, conference, or athletic association named in them. The pacing report's college is invented.
