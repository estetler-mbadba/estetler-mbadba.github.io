# College data projects

The home page for three college data projects built with SQL and an AI coding agent: a weekly admissions pacing report on synthetic records, and two analyses of public federal records.

**Live page:** https://estetler-mbadba.github.io/

| Project | Live | Code |
|---|---|---|
| Weekly admissions pacing report | https://estetler-mbadba.github.io/admissions-pacing-report/ | [admissions-pacing-report](https://github.com/estetler-mbadba/admissions-pacing-report) |
| Five Colleges of Ohio enrollment atlas | https://estetler-mbadba.github.io/ohio-five-enrollment-atlas/ | [ohio-five-enrollment-atlas](https://github.com/estetler-mbadba/ohio-five-enrollment-atlas) |
| Athletics Benchmarking Explorer | https://estetler-mbadba.github.io/athletics-benchmarking-explorer/ | [athletics-benchmarking-explorer](https://github.com/estetler-mbadba/athletics-benchmarking-explorer) |

This page is static HTML and CSS with no build step. The projects are independent work. The two built on public records are not affiliated with or endorsed by any college, consortium, conference, or athletic association named in them. The pacing report's college is invented.
